# Basin Wildcats Basketball Club: homepage concept

Homepage concept for The Basin Wildcats Basketball Club (basinwildcats.com),
built by 3P Digital for client review. Static HTML/CSS/JS served from GitHub
Pages; the production build moves to Next.js on Vercel once the direction is
signed off.

- Strategy brief and house rules: `CLAUDE.md`
- Asset register and image generation prompts: `docs/build-brief.md`
- Copy sources: the club's current WordPress site (history, about, sponsors).
  Stat chips carry real club numbers only.

Local preview: open `index.html` in a browser. No build step.
